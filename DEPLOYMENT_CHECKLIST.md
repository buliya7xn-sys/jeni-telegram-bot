# Deployment checklist
- [ ] Configure BOT_TOKEN and OWNER_ID in host environment (do not commit secrets).
- [ ] Use the same bot token when migrating the existing bot identity.
- [ ] Keep `data/` and `backups/` on persistent storage.
- [ ] Add bot as admin to official channel for membership checks and set the correct channel username/ID.
- [ ] Add bot as admin in target group with Delete Messages and Ban Users permissions.
- [ ] Add bot as admin in feedback channel and run `/setfeedbackchannel @YourChannel`.
- [ ] Run `/backup`, then test `/restore` using a copy of a backup before relying on it.
- [ ] Test Join/Verify, updates, broadcast to a small test set, feedback album, warning escalation, temporary bans, and reset warnings.
- [ ] Configure allowed links and custom profanity words with `/setallowedlinks` and `/setprofanity`.
- [ ] Keep an off-server copy of backups.
